# Regulação — usuário

1. No **atendimento clínico**, escolha um procedimento pré-regulado (ou digite fora do protocolo).
2. Informe CID quando exigido, prioridade e resumo → **Enviar à regulação**.
3. Em **Regulação** (`/regulacao`), abra a solicitação.
4. Classifique por cor, **Autorize** (com data sugerida se quiser), **Devolva** por falta de dados ou **Negue** com motivo clínico.
