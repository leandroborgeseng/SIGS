# Manual do usuário — Unidade e código IBGE

**Status:** stub  
**RF:** RF-2.47

1. Abra **Unidades** no menu Cadastros.  
2. Selecione a unidade e informe o **IBGE do município** (7 dígitos).  
3. Franca/SP = `3516200`.  
4. Salve — esse código entra automaticamente nas fichas de produção.

Sem IBGE, o pré-envio de produção alerta risco de rejeição.
