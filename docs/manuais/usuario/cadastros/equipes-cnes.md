# Equipes CNES — quem faz parte

**Versão:** 0.1.0  
**Tela:** `/equipes`

## O que faz

1. Lista as **equipes da rede Prefeitura** (Franca).
2. **Clique** numa equipe para ver os **membros** (nome, CNS, função/CBO).
3. Painel **«Em mais de uma equipe»** mostra quem aparece em mais de uma lotação com INE diferente.
4. Tipos de equipe vêm com **nome legível** (ex.: código **76** = **EAP — Equipe de Atenção Primária**), não só o número.

## Como usar

1. Em **Auditoria CNES** ou **Unidades**, sincronize a rede municipal (se ainda não houver equipes).
2. Importe profissionais lotados (botão na própria tela `/equipes` ou na auditoria).
3. Abra **Cadastros → Equipes** (`/equipes`).
4. Clique no nome da equipe para abrir `/equipes/[id]` com a lista de membros.
5. Use a aba **Multi-equipe** para quem está em mais de uma equipe.
6. **Exportar CSV rede** baixa unidades × equipes × profissionais.

Sem dados de pacientes — apenas cadastro público CNES (nome + CNS + CBO).

Ajuda técnica: `docs/manuais/tecnico/cadastros/equipes-cnes.md`.
