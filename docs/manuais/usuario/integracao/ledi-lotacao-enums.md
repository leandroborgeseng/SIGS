# Manual do usuário — Produção LEDI (lotação)

**Status:** stub (UI de produto fase 2)  
**RF:** RF-10.3 / RF-10.20

## O que o município precisa

1. Cada profissional que atende deve ter **lotação ativa** na unidade (CBO + equipe com INE quando for APS).  
2. Telas: **Lotações** no menu.  
3. Ao **finalizar** consulta ou registrar vacina, o sistema monta a ficha de produção com esses dados.  
4. Sem lotação, a finalização é bloqueada — cadastre antes.

Ajuda técnica: `docs/manuais/tecnico/integracao/ledi-lotacao-enums.md`.
