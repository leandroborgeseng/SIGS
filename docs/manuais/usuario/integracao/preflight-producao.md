# Pré-envio — usuário

1. Em **Produção**, clique **Avaliar antes de enviar**.
2. Leia o relatório:
   - **O que impede enviar** (bloqueios)
   - **Risco de perder produção / dinheiro** (CBO, SIGTAP, CPF/CNS, etc.)
   - Checklist e detalhe por lote
3. Corrija o que faltar (paciente, lotação em `/lotacoes`, SIGTAP em `/sigtap`, refazer atendimento).
4. Só então **Enviar produção**.
5. **Enviar mesmo assim** só com ciência de que pode haver glosa/perda.
