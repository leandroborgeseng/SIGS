# Prescrição — usuário

1. Abra o **atendimento clínico** e role até **Prescrição**.
2. Selecione um medicamento do **catálogo municipal** **ou** digite um nome fora do padrão.
3. Informe dose, frequência, duração e via → **Adicionar prescrição** (rascunho).
4. Em **Receitas** (`/prescricoes`) ou no link da lista, **Emitir** a receita. Fora do padrão pede confirmação.
5. Use **Imprimir** na tela da receita para o receituário.
