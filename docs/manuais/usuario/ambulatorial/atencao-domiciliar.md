# Atenção domiciliar — usuário

1. Abra **Atenção domiciliar** e selecione a unidade.
2. Informe paciente, profissional, modalidade (**AD1 / AD2 / AD3**) e turno.
3. O procedimento padrão `0101040024` alimenta o BPA stub.
4. Clique **Registrar visita** e depois **Finalizar**.
5. Em **Produção**, exporte o BPA e confira a linha domiciliar no SIGTAP.
